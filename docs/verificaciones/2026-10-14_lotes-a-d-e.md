## Lote D: la API de series de datos.gob.ar devuelve datos incompletos

La API `apis.datos.gob.ar/series` responde con observaciones vacías que varían de una consulta a otra. La misma serie (300.1_AP_PAS_DEPROS_0_M_30) devolvió 201 observaciones con valor en una consulta y 334 en la siguiente, con minutos de diferencia. En la serie de posición de reserva en el FMI (SRC-0304) la API devolvió el encabezado sin ningún dato.

Entre ellos están los 44 meses que `unresolved.md` describe como vacíos en los derechos de exportación del IMIG (SRC-0306), y 133 meses de los depósitos del Gobierno Nacional en el BCRA (SRC-0305).

**Regla para adelante:** las series de datos.gob.ar se toman del archivo estático de la distribución y se usa la API sólo para descubrir la `downloadURL`.
